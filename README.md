# Vibe 图解 · 作品目录

[English](README.en.md) | 中文

在浏览器里观看技术动态图解。首页列出可观看的作品，每部作品有自己的页面。

当前作品：**Hadoop 生态圈**。跟随一批电商订单，看数据如何落盘、并行计算，再变成报表和订单查询。V1.2 共 **10 章、59 镜、7 分 15 秒**，16:9 横屏，无音频，不导出视频。

## 快速开始

需要 Bun 1.3.14（已验证）。在项目根目录执行：

```sh
bun install --frozen-lockfile
bun run dev
```

打开终端显示的地址（默认 `http://127.0.0.1:3000/`），点击首页的「Hadoop 生态圈」进入 `/works/hadoop/`。片内可拖动进度、跳转章节或全屏。播放区获得焦点时，空格播放/暂停，左右方向键后退/快进 5 秒。进度条获得焦点时使用原生键盘操作。窄屏下，播放器下方也会显示当前字幕。

```sh
bun run typecheck
bun test
bun run build
bun run preview
```

## 添加作品与部署

1. 新建 `works/<作品名>/index.html`（目录名用小写字母、数字或连字符）。把该作品的代码和资源放到自己的目录，用相对路径引用。
2. 在根目录 `index.html` 的作品列表添加链接 `./works/<作品名>/`。作品页用 `../../` 返回首页。开发服务重启后会识别新入口。
3. `bun run build` 会构建首页和所有作品页。将整个 `dist/` 发布到支持目录 `index.html` 的静态托管；可放在域名根目录或同一域名的子目录下，保留目录结构。不需要服务器运行 Bun。`bun run preview` 可先预览构建结果。
