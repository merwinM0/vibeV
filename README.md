# vibeV · 作品目录

[English](README.en.md) | 中文

在浏览器里观看章节化科普图解。首页列出可观看的作品，每部作品有自己的播放页。

原版作品：**Hadoop 生态圈**。跟随一批电商订单，看数据如何落盘、并行计算，再变成报表和订单查询。全片 **10 章、约 3 分 11 秒**。按 `p1` → `p4` 的原顺序连续播放配音，字幕和画面跟随实际口播。画面为 16:9 横屏，不导出视频。

## 快速开始

需要 Bun 1.3.14（已验证）。在项目根目录执行：

```sh
bun install --frozen-lockfile
bun run dev
```

打开终端显示的地址（默认 `http://127.0.0.1:3000/`），点击首页的「Hadoop 生态圈」进入 `/works/hadoop/`。点击「播放」开始听配音，可静音、拖动进度或全屏。当前章始终居中；在章节栏滚动、横划或点击即可切换章节。播放区获得焦点时，空格播放/暂停，左右方向键后退/快进 5 秒。进度条获得焦点时使用原生键盘操作。窄屏下，播放器下方也会显示当前字幕。

### 新版 Hadoop 样片

在首页打开「从 MC 交易日志到 HDFS · 样片」（`/works/hadoop-data-hdfs/`）。这段 **1 分 46 秒无声图解**用同一个 B2 展示写入、读取、失联改读和补副本，支持跳章、逐镜、拖动和全屏。保留旧版深色外壳。角色从一张橡木交易单切入，按操作台、放下 B2、坐着查位置和改读。头部缩放按更密的模拟口播节拍预演。详见[样片分镜](works/hadoop-data-hdfs/分镜.md)与[制作规范](vibe-make/SKILL.md)。

### MC 角色动画样片

在首页打开「一张皮肤，怎么让角色动起来？」（`/works/mc-avatar/`）。30 秒样片只提供配音版，白字细黑描边字幕按实际口播开合，角色动作跟随关键词；下方可预览共享动作库（含托腮、坐姿、侧卧）、转动视角或本地换一张 64×64 PNG 皮肤。

需要重新剪接原始录音时，使用带 libmp3lame 的 FFmpeg 运行 `bun run avatar:dub`。导出时，安装 Chromium 和带 libx264 的 FFmpeg，运行 `bun run avatar:render`；如果 Chromium 不在 `PATH`，用 `env CHROMIUM_BIN=/你的浏览器路径 bun run avatar:render`。生成的 `exports/mc-avatar-30s.mp4` 是 1080p、30 fps 的配音版。详见 [分镜与复用说明](docs/MC角色样片.md)。

### 设置首页封面

首页宽屏排五列，窄屏自动减少列数。封面按 16:9 居中裁切，未上传时显示灰色占位。在播放页下方的「作品封面」里选择图片，再点击「上传封面」；重新上传可替换，点击「移除封面」可恢复占位。支持 PNG、JPEG、WebP，最大 5 MB。封面保存在自动创建的 `db/covers.sqlite`，重启本地服务后仍有效。

```sh
bun run typecheck
bun test
bun run build
bun run preview
```

## 添加作品与部署

1. 新建 `works/<作品名>/index.html`（目录名用小写字母、数字或连字符）。把该作品的代码和资源放到自己的目录，用相对路径引用。
2. 在根目录 `index.html` 添加 `./works/<作品名>/` 链接，在封面占位上用 `data-cover` 指定同一个目录名。需要上传时，参照 `works/hadoop/index.html` 复用封面表单、样式和脚本，把 `data-cover-editor` 改成新目录名。作品页的 `vibeV` 用 `../../` 返回首页。新增入口后重启开发服务。
3. `bun run build` 会构建首页、作品页和当前封面快照。发布整个 `dist/` 到支持目录 `index.html` 的静态托管，域名根目录和子目录都可用。静态站只读；改封面后需要重新构建并发布。`bun run preview` 可预览构建页面，但封面读取的是本机实时数据库。开发和预览服务仅监听本机，不要把上传接口对公网开放。
