# 《一张皮肤，怎么让角色动起来？》30 秒动作样片

用项目里的 `avatar/mc_mon.png` 讲清三件事：一张图提供各面的外观，关节提供局部旋转，时间决定旋转到哪一步。面向初学者；演示的是本项目的轻量方块角色，不把示意步态当成 Minecraft 游戏引擎的实现。贴图是用户提供的原始 64×64 RGBA PNG，透明外层和细手臂布局按源图保留。

**规格**：1920×1080、30 fps、900 帧；中文画内字幕，无配音和配乐。网页里可播放样片和单独预览姿态；MP4 不包含网页控件。验收参考采用月白底、青黑正文、青色连接线，与角色原贴图的红色形成区分。除皮肤外不使用外部绘图素材。

| 镜号 | 时间 | 字幕 | 关键画面与验收 |
|---|---|---|---|
| 01 | 00–05 s | 这张小小的皮肤，怎么变成会走的角色？ | 原图在左，角色马上向舞台中央走入。停住时贴图上的脸、衣服和左右肢体仍可辨。 |
| 02 | 05–11 s | 我们先把皮肤分配给头、身体和四肢。 | 依次高亮六个部件各自的贴图区域；右边对应部位亮起并给出侧视角，原图使用最近邻放大。 |
| 03 | 11–17 s | 颜色来自贴图。抬手，靠的是让手臂绕肩转。 | 角色指向教学图；右侧肩关节示意图同步从自然垂臂转到抬臂，再给读图时间。 |
| 04 | 17–24 s | 走路时，左腿和右臂一起向前；下一步交换。 | 侧前方看交替步态；同时标出两组对侧肢体，无须只凭颜色区分。 |
| 05 | 24–30 s | 皮肤不换。换一组关节动作，就能演出下一幕。 | 同一角色转向、点头、最后定格；片尾保留「贴图定外观，关节定动作」。 |

角色预览页允许本地换 PNG、选择「自动／标准／细手臂」、调角度和时间。换图只作用于角色预览，不会上传或替换样片中的原图。自动识别以两条手臂贴图区的透明空列为线索，非规范贴图可手动选择。角色由盒面及刚性转轴组成，不做布料、连续网格变形或物理步态。

## 在其他作品里复用

用 `avatar/skin.ts` 的 `prepareSkin(image)` 解码贴图一次，然后在现有场景的绘制函数里使用 `avatar/draw.ts` 的 `drawAvatar`：

```ts
drawAvatar(ctx, skin, {
  x: 1240, y: 810, scale: 15, yaw: 0.28,
  action: 'point', time: localFrame / 30,
});
```

`x` 和 `y` 是脚底位置，`scale` 是每个模型像素的绘制比例，`yaw` 为弧度。动作可选 `idle`、`walk`、`look`、`point`、`nod`。`time` 用镜头的局部秒数，不另外计时；这样播放、跳转和导出使用同一帧姿态。可用 `intensity: 0` 绘制静止姿态。样片的 `works/mc-avatar/film.ts` 是完整例子。
