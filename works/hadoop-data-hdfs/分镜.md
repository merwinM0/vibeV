## 合成与审核

`timeline.ts` 记录同一帧上的镜头、字幕、节点和 `storyCues`；`acting.ts` 只排位置、动作 ID 和说话窗口，`avatar/performance.ts` 提供通用姿势、肘膝与位移插值。`diagram.ts` 绘路线，`stage.ts` 计算机位和回波，`host.ts` 绘角色、台面和道具。句段内约 **4 次/秒**、峰值约 **1.5–2.1%** 的微缩放只作用于头部，停顿复位；这是模拟节拍。减少动态效果时仍可读相同结果，不播步态、路径光点、推镜、回波和头部缩放。

运行 `bun run dev`，打开 `/works/hadoop-data-hdfs/`。优先看 **00:00–00:08** 的收单与亮图、**00:15–00:18** 的放块、**00:28–00:44** 的连续走坐和查位置、**01:07–01:22** 等待后改读，以及 **01:40** 之后的侧卧收束。全片其他阶段未扩做。已在 Chromium 抽查桌面、390px 窄屏、主题继承、动作/道具关键帧、拖动、章节、全屏和减少动态效果；正式录音后再对齐讲话窗口。
