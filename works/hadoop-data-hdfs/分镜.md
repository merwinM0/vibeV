# HDFS 读写与失联恢复｜样片分镜

依据：[口播稿](配音稿.md)第 06、07 章节选、[案例与查证](article.md)。规格：16:9，1920×1080 设计坐标、30 fps，共 3,180 帧（01:46），网页无声版。全片时长不锁定；这里的图解短句不是逐句口播字幕，无录音剪接表。

- 样片跟踪放大案例的 B2：甲、丁在机架一，乙、丙在机架二。上方是控制和元数据，下方是文件字节。控制请求、确认和指令均为虚线，字节路线为实线。授权后再铺开采集、清洗、切块、NameNode HA 和片尾练习。
- 资料依据皆见 [article.md](article.md) 的 Apache Hadoop 3.3.6 对照表。读写泳道追踪一次代表性传输，不逐条呈现底层协议。校验失败和心跳失联是两个独立假设。
- 网站继承旧版 Hadoop 的共享深色主题，不覆盖全站底纹与顶栏。影片用深炭底、亮青数据线、琥珀控制线、珊瑚故障色，加箭头与文字。白字细黑描边、无底框，控件在舞台外；窄屏补大字号说明和副本计数。
- 角色无固定框，按镜头改变站位和尺度。可经过次要网格或机架提示，重点标签、路线和状态须清楚；推镜不带动字幕。路径光点区分当前方向，节点收到后短暂出现回波。

## 合成与审核

`timeline.ts` 是镜头状态来源，`diagram.ts` 绘路线与尾点，`stage.ts` 计算推镜和回波，`host.ts` 驱动站位、道具和姿势。播放、跳章、逐镜与拖动共用一份 30 fps 帧状态；减少动态效果时取消移动光点、回波、推镜和讲话缩放，保留状态、字幕和静态道具提示。没有正式配音时，用几个模拟重音让头部围绕中心从 `1.00` 轻缩放至约 `1.024` 再复位，皮肤内外层同时变化；读图停顿回到 `1.00`。这不是实测对口型。

从根目录运行 `bun run dev`，打开 `/works/hadoop-data-hdfs/`。验收优先看 **00:15–00:38** 的写入与反向确认，以及 **01:15–01:40** 的改读、调度和回补；还需确认动作在正常速度下是否明显、会不会抢图解。页面支持跳章和逐镜定位。确认样片的画面语法后，再制作完整八章；若之后加入配音，按实录定位重音和字幕，复核各镜时长。

已用 Chromium 检查桌面与 390px 窄屏、播放暂停、键盘跳转、全屏、减少动态效果和回跳状态；原作品入口仍可打开。另核对首页、旧版与新样片的共享主题及几何背景相同，并抽查 B2 的持有、放下、回波和读图关键帧。当前没有配音或视频文件可供听审。
